## ركّبها في دقيقة

| بتستخدم إيه؟ | الطريقة |
|---|---|
| حساب Claude أو ChatGPT | نزّل [`marsad-design-director.zip`](https://github.com/Marsadgrouplabs/marsad-design-director/releases/latest/download/marsad-design-director.zip) وارفعه من قسم Skills |
| Claude Code | `claude plugin marketplace add Marsadgrouplabs/marsad-design-director` |
| Claude Code أو Codex بسكربت | حمّل الـ repo وشغّل `install.ps1` أو `install.sh` |

<details>
<summary><b>الخطوات بالتفصيل</b></summary>

### حساب Claude أو ChatGPT

1. نزّل [`marsad-design-director.zip`](https://github.com/Marsadgrouplabs/marsad-design-director/releases/latest/download/marsad-design-director.zip) وماتفكّهوش.
2. **Claude:** افتح قسم Skills في حسابك واختار رفع ملف.
3. **ChatGPT:** افتح Skills، ثم Create، ثم Upload from your computer. الميزة متاحة حسب خطة الحساب.

### Claude Code كـ Plugin

```bash
claude plugin marketplace add Marsadgrouplabs/marsad-design-director
claude plugin install marsad-design-director@marsad-marsad-design-director
```

### ويندوز

```powershell
git clone https://github.com/Marsadgrouplabs/marsad-design-director.git
cd marsad-design-director
powershell -ExecutionPolicy Bypass -File .\install.ps1
```

### ماك أو لينكس

```bash
git clone https://github.com/Marsadgrouplabs/marsad-design-director.git
cd marsad-design-director
bash install.sh
```

السكربت بيركّبها لـ Claude Code في `~/.claude/skills` ولـ Codex في `~/.agents/skills`، ولو فيه نسخة قديمة بيحتفظ بيها.

</details>
